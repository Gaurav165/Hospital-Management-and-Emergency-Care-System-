MediCore shows how an OS manages a hospital: emergencies get CPU priority (Scheduling), lab/pharmacy requests share a bounded buffer (Synchronization), imaging/printer/DB are granted only in safe states (Banker's), and each task gets memory (Allocation).

Patients & Emergency Queue

Queue is sorted Critical → Urgent → Routine, then by arrival: emergencies are served first, like priority scheduling.

CPU Scheduling

PIDCompletionTurnaroundWaiting

Emergency tasks get priority 1 so the CPU serves them before routine work, cutting life-critical waiting time. Priority and SJF here are non-preemptive: a running task is never interrupted.

Producer–Consumer (Bounded Buffer, size 5)


 
Semaphores: empty = free slots, full = filled slots, mutex = lock around buffer access. Producer waits if empty=0; consumer waits if full=0. This is a single-threaded model of the idea, not real concurrency.





Banker's Algorithm

 

 

 

 
Resources: CPU slots, Imaging units, Printer slots, DB connections. Need = Max − Allocation. A request is granted only if the resulting state still has a safe sequence.





Memory Management (simulated, not real RAM)

 

 
 

 

 
ProcessSizeStatus

 
External fragmentation: enough total free memory exists, but no single hole is big enough. Internal fragmentation does not occur here because blocks are split exactly.
